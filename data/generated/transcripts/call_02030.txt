Romaine Jast (VP Marketing): Directionally, yes. I would not call it a pure lift because the more engaged customers were also more likely to enter the journey. We’re trying to improve the comparison group.

Amelia Hart (Account Executive): That’s a thoughtful caveat. How is the reporting conversation going with finance?

Romaine Jast (VP Marketing): Better, because the numbers are visible. We can connect a portion of online revenue to campaigns. Store sales are still imperfect because customers do not always use the same identifier at checkout.

Amelia Hart (Account Executive): Are there plans to address that through loyalty data?

Romaine Jast (VP Marketing): Yes, but slowly. The loyalty database has older records and some duplicates. We are cleaning it in stages. I don’t want to merge aggressively and accidentally combine households.

Amelia Hart (Account Executive): Sensible. We can keep the current matching rules conservative. Which use case should we prioritize next?

Romaine Jast (VP Marketing): Lapsed customers. We have a seasonal retail pattern, and some people buy only once or twice a year. A generic “we miss you” email is not enough; the timing should reflect category and last purchase.

Amelia Hart (Account Executive): Would categories come from the product feed?

Romaine Jast (VP Marketing): Eventually. For now, we can start with broad categories. The team wants to avoid a six-month data project before seeing any benefit.

Amelia Hart (Account Executive): We can design a first version with the fields already available, then enrich it later. What constraints should we account for?

Romaine Jast (VP Marketing): Language. Dutch and French versions need separate review, and the translations are not always ready at the same time. A journey should not send an English fallback just because one translation is late.

Amelia Hart (Account Executive): We can add a hold condition for missing localized content. Would you prefer one journey with branches or separate journeys by language?

Romaine Jast (VP Marketing): One governed journey if the branches remain understandable. We had too many separate campaigns before, and nobody knew which version was current.

Romaine Jast (VP Marketing): The in-store event is the tricky one. Attendance is tracked on paper in two locations, so it will not be a clean automated trigger. We can import a list afterward, but that changes the timing.

Amelia Hart (Account Executive): Would a scheduled import be adequate?

Romaine Jast (VP Marketing): For that event, yes. I’d rather be honest about a manual step than pretend every process is real time.
