Lazaro Ferry (Marketing Operations): We coordinate professional-development programs for several schools. Marketing owns the newsletters, admissions sends event invitations, and the program teams send follow-ups from different tools. There is no single journey view.

Priya Shah (Account Executive): What is the consequence of that lack of view?

Lazaro Ferry (Marketing Operations): Duplicate messages first. Someone registers for an information session, then receives the general newsletter and a separate reminder that does not know they already attended. It is not catastrophic, but it looks careless. We also spend too much time checking spreadsheets.

Priya Shah (Account Executive): How are contacts collected?

Lazaro Ferry (Marketing Operations): Website forms, event platforms, imports from partner schools, and occasionally a CSV from admissions. The fields are not consistent. One team calls a program “Executive MBA,” another uses an internal code, and the same person can appear with two email addresses.

Priya Shah (Account Executive): When you find duplicates, who resolves them?

Lazaro Ferry (Marketing Operations): Usually me or one of my analysts. We compare names manually, which is not ideal. We cannot always know whether two addresses belong to the same person, particularly with employer addresses.

Priya Shah (Account Executive): So identity matching is a concern. Is the primary goal a cleaner database, better campaign execution, or reporting?

Lazaro Ferry (Marketing Operations): Campaign execution. The database cleanup matters because it affects campaigns, but we are not buying a data-governance project. We need to segment by program, location, language, and lifecycle stage without asking three teams for a fresh spreadsheet every week.

Priya Shah (Account Executive): What does a typical campaign look like today?

Lazaro Ferry (Marketing Operations): A program manager sends a request by email. I check the list, remove people who opted out, format the content, send a test, and wait for approval. For events, admissions sends a separate attendee file afterward. Follow-up is often two or three days late.

Priya Shah (Account Executive): What would you want automated first?

Lazaro Ferry (Marketing Operations): Event registration confirmation and reminders. Then a follow-up based on attendance. If they registered but did not attend, the message should be different. That is the obvious use case.

Priya Shah (Account Executive): Do you currently receive attendance status from the event platform?

Lazaro Ferry (Marketing Operations): Eventually. Sometimes it arrives the next morning, sometimes someone emails us a spreadsheet. We would need to understand whether a delayed status can update a journey safely.

Priya Shah (Account Executive): That is a good technical question for a later session. For discovery, what timing would make the program successful?

Lazaro Ferry (Marketing Operations): If we could launch a reminder within an hour of registration and have the attendance follow-up ready the next day, that would be a major improvement. But it must not send to people whose consent has changed since registration.

Priya Shah (Account Executive): How is consent recorded now?

Lazaro Ferry (Marketing Operations): In three places. The website has a checkbox, the event platform has its own setting, and admissions has a paper-to-digital process for some partner programs. We reconcile them in a master sheet. That is one of the reasons I am cautious.

Priya Shah (Account Executive): Cautious about the platform or about the source data?

Lazaro Ferry (Marketing Operations): Both. Automation can make a bad rule operate faster. I do not want a vendor to say, “Just import everything and clean it later.” For education, people can be prospective students, current learners, alumni, or employers, and the communication permissions are not interchangeable.

Priya Shah (Account Executive): That distinction should be part of the design. We would start with a field and consent map, then choose a narrow pilot. Which program could provide a representative but manageable test?

Lazaro Ferry (Marketing Operations): The continuing-education certificate program. It has about four thousand contacts, regular events, and a small team. It is less politically complicated than admissions.

Priya Shah (Account Executive): That sounds appropriate. Would the pilot include the master database or only new registrations?

Lazaro Ferry (Marketing Operations): New registrations first. We have a large historical file, but importing it before we understand the rules would make troubleshooting difficult.

Priya Shah (Account Executive): What systems would need to connect for that pilot?

Lazaro Ferry (Marketing Operations): Our website form tool, the event platform, and the email system we use today. We also have a student-information system, but I would keep that out of phase one.

Priya Shah (Account Executive): Excluding the student-information system reduces complexity. Would the existing email system remain active during the pilot?

Lazaro Ferry (Marketing Operations): Yes. We cannot shut it off. We need a transition period, and we need to avoid sending the same campaign from both systems.

Priya Shah (Account Executive): Then the pilot plan should identify campaign ownership and use suppression rules between systems. Who would approve the pilot?

Lazaro Ferry (Marketing Operations): My director approves the operational design. Privacy reviews consent handling. Admissions and the program manager approve the message content. IT will review connections, though they are not looking for a large implementation this year.

Priya Shah (Account Executive): Is budget already allocated?

Priya Shah (Account Executive): Can you estimate the manual effort today?

Lazaro Ferry (Marketing Operations): About two days per event cycle, sometimes more when admissions sends a late file. That is across me and one analyst. But saving time is not enough; the reputational cost of an incorrect message is what gets attention.

Priya Shah (Account Executive): How would you measure that reputational risk?

Lazaro Ferry (Marketing Operations): Complaints, unsubscribe spikes, and internal escalations. We do not have a perfect baseline. We can compare the pilot against the previous two event cycles, although the audiences will not be identical.

Priya Shah (Account Executive): That is still a useful directional comparison if we document the difference. Are there any requirements around language or regional hosting?
