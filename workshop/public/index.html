Build · 30 min

Have Claude build the system

Paste this into Claude Code. You’re not running a finished tool: Claude designs and builds the system, then uses it to make the page you saw at the start.

I want a Claude artifact built from the ACME Email call transcripts in this repo that shows:
1) a summary of all the calls with sentiment and product insights extracted
2) a drill-down into each segment to see which calls contributed
3) a final drill-down with the per-call analysis and the relevant sections of the transcript highlighted

To do this, build a system that uses Claude Sonnet subagents to process the calls and stores the segmented results in a SQLite database. Use only the 200 calls listed in data/class-slice.txt. The transcripts are in data/generated/transcripts, and the account, opportunity and call metadata is in data/generated.

Build all of this out, then publish the page as an artifact. Match the style of https://fullstackgtm.com/ai-in-gtm-class, and use https://impeccable.style/slop/ to remove slop.
  1. 1
    Plan

    Claude reads the repo and the two style links, then lays out how it will split the work. Read the plan and tell it to go.

  2. 2
    Read in parallel

    Sonnet subagents each take a batch of calls and write what they find. This is the slow part.

  3. 3
    Store

    The results go into a SQLite database: one row per call, insight and quote.

  4. 4
    Publish

    Claude builds the page from the database and publishes it as an artifact. Open the link it gives you.

Approve file writes and commands when Claude asks. If it stalls or asks a question, answer it and let it continue. Your page won’t match the one from the start exactly; that’s the point of the next step.

Check · 8 min

Make it prove its work

Before you trust a page like this, ask Claude to check it against its own database and the transcripts.

Check the artifact you just built against your SQLite database and the transcripts.

1. Confirm all 200 calls in data/class-slice.txt were processed, and list any that weren't.
2. Recount the calls behind the three biggest segments on the page straight from the database. Do they match?
3. Pick two highlighted passages and confirm each appears word for word in its transcript file, said by the person shown.
4. Name anything on the page the data doesn't support.

Give a short pass or fail for each, then fix what failed and republish the artifact.
